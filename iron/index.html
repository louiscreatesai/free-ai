IRON: a real Jarvis that runs on your Claude plan

This is a free, open source project called JARVIS. It's MIT licensed. You say "Hey Jarvis" and it wakes up, listens, and does things through your tools. It can search the web, make images and read your mail. The face is a web page with an Iron Man style hologram, and the brain is Claude Code.

What you need

  • A Claude Code subscription, installed and logged in. It uses that login, so there is no API key and no extra bill.
  • Node.js 20 or newer.
  • Google Chrome or Microsoft Edge in a real browser window. Preview panes inside editors block the microphone.
  • Optional: an ElevenLabs key for a better voice. Without it, Jarvis uses your browser's own speech.

Set it up

git clone https://github.com/charlesdove977/jarvis.git
cd jarvis
npm install
npm start
  1. Open http://localhost:5173 in Chrome.
  2. Click INITIALISE and allow the microphone.
  3. Say "Hey Jarvis".

Run npm run setup first if you want it to check your computer in plain language. Or open the repo in Claude Code and say: "Read the README and set this up for me, one step at a time."

Good to know

  • It was built by someone else, not me. Credit goes to the author, charlesdove977 on GitHub.
  • Jarvis uses the MCP servers already connected to your Claude Code. Web search, image making, your mail and your phone each need a matching tool connected. Without one, that skill is missing.
  • It starts read-only. Search and image making run freely, but anything that sends or drives your phone needs you to switch it on. The README explains how.
  • Claude does the work, so it counts against your Claude plan usage.
