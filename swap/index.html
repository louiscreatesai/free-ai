SWAP: the free code that swaps a person in any video

What it is

Genjustsu is an open-source workflow by Sirio Berati. You upload a video, it masks the person, the background or an object, and a video model generates a new version with your swap. Your original audio goes back into the final video.

The code is free (MIT license, about 900 stars on GitHub). The video generation is not: it runs on two paid services, so you pay for each swap you make, and nothing else.

Get it here: github.com/sirioberati/Genjustsu-Open-Source-Workflow

What you need

  • Python 3.12 or newer.
  • A Mac, Linux, or Windows with WSL2. Native Windows is not supported.
  • An Enhancor API key (makes the video) and a Replicate API token (makes the masks). The repo's README links both. Both are paid by use, so check their prices first.
  • No graphics card. The heavy work runs on their servers.

1. Get the code

On the GitHub page, press Code, then Download ZIP, and unzip it.

2. Install the tools it needs

Mac:

brew install rubberband cloudflared

Ubuntu or Windows WSL2:

sudo apt install rubberband-cli python3-venv

3. Set it up

Open a terminal in the folder and run:

bash setup.sh

Open the new .env file and add your two keys:

ENHANCOR_API_KEY=your key
REPLICATE_API_TOKEN=your token

Check it:

.venv/bin/python doctor.py --require-keys

4. Start the screen with buttons

bash start.command

Open http://127.0.0.1:8770. Upload an MP4 or MOV, prepare it, check the mask, then make a draft. Only press the 1080p button once you like the draft. Do not retry a generation blindly, because each try can be charged.

Use it from your AI agent

Open the folder in Claude Code (or another agent that can run Python) and ask it to follow AGENTS.md and .agents/skills/tein-video-workflow/SKILL.md. Then ask for your swap in plain words. Tell it to wait for your OK before anything paid.

Honest notes

  • The tool is free, the generations are not. Each draft and each HD render costs money on your Enhancor and Replicate accounts.
  • It is a local single-user app. Keep it on your own computer, and do not put it online without adding a login.
  • Only swap people who agreed to it, and do not use it to pass a swapped video off as real. It is for your own videos and for fun.
  • The code is MIT. The author's names, logos and example media are not covered by that license.
