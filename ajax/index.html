AJAX

PewDiePie's free AI app (Odysseus), ready for Ajax

What it is

PewDiePie just showed Ajax, his own AI: a small model (about 9 billion parameters, built on Qwen 3.5) trained to search the web, handle email and run your calendar, right on your own computer. OpenAI banned his account twice while he built it, because he used its outputs to help train Ajax.

When I checked on 16 Oct 2026, I couldn't find a public download of Ajax. What you can run today is Odysseus, his free, open-source AI workspace, which has more than 93,000 stars on GitHub. It's where Ajax runs. Chat, agents, research, documents, email, notes and calendar, on your own machine, with no telemetry.

Get it here: github.com/odysseus-dev/odysseus

1. Install Docker

Odysseus runs in Docker. On Windows or Mac, install Docker Desktop and open it once so it's running.

2. Download and start Odysseus

Open a terminal (PowerShell on Windows), paste these one at a time:

git clone https://github.com/odysseus-dev/odysseus.git
cd odysseus
cp .env.example .env
docker compose up -d --build

On Windows PowerShell, use copy .env.example .env for the third line.

The first start takes a few minutes while it builds.

3. Open it

Go to http://localhost:7011 in your browser once the containers are healthy. The first admin password is printed when you run docker compose logs odysseus.

4. Pick a model that fits your computer

Open the Cookbook. It gives hardware-aware model recommendations, downloads and serving, so you only see models that fit your computer. Start with a small one. You can also connect OpenAI or Claude with your own key if you want, but you don't need to.

5. When Ajax drops

Ajax runs inside Odysseus, so when PewDiePie releases it you'll just add it as a model. Follow @louiscreates.ai and I'll post the moment it's out.

Honest notes

  • If anyone else can reach your computer on the network, keep AUTH_ENABLED=true in the .env file (the README says so).
  • Local models need a decent amount of RAM, and run faster with a graphics card. The Cookbook only suggests what fits.
  • Odysseus is AGPL-3.0 licensed open source.
