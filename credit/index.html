Claim your free Claude credit (up to $250)

Anthropic is giving existing Claude subscribers a one-time credit for Claude Code cloud sessions: $100 on Pro, $250 on Max. You have to claim it by October 7.

Claim it (about a minute)

  1. Open Anthropic's claim page: claude.ai/code/claim-credit/10 and log in with your Claude account. Already use Claude Code in the terminal? Run /claim-credit instead.
  2. Connect GitHub when it asks. A cloud session can't start without it.
  3. Start a cloud session at claude.ai/code. Cloud sessions spend the credit first, before your normal plan usage.

Good to know

  • It's for existing Pro and Max subscribers. Free accounts don't get it.
  • It only covers cloud sessions: Claude Code running on Anthropic's machines, so it keeps working after you close your laptop.
  • Claim by October 7. Terms apply, and the claim page shows them.
  • Source: Anthropic's announcement from @ClaudeDevs and the follow-up about how it's spent.
