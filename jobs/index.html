JOBS: the free AI job hunter that runs on Claude Code

What it is

ai-job-search is a free (MIT) framework built on Claude Code with about 58,000 GitHub stars. You give it your CV once. For each job post it scores how well you fit, drafts a tailored CV and cover letter, and has a second agent review both. It also preps interviews and tracks the answers you get back. It never sends anything for you: drafts only.

The creator says 69 applications turned into 20 first interviews and one signed contract. That is one person's result, not a measured outcome. It is not affiliated with Anthropic.

Before you start

  • A paid Claude plan (Pro, Max or Team) or Anthropic API credits. Claude Code has no free tier.
  • Python 3.10+, Bun, and a LaTeX install with lualatex and xelatex (for the CV PDFs).
  • Use a PRIVATE repository (not a fork). Setup writes your personal data into tracked files, and a public copy would publish it.

1. Get it

Do not fork it: a fork of this project is always public (GitHub does not allow private forks), and setup writes your personal data into tracked files. Instead create a NEW PRIVATE repository, add the original project as upstream, and clone your private one. The project's README links the two-minute recipe (SETUP.md, section 8).

2. Install the job site tools

python3 tools/install_portal_clis.py

3. Set up your profile

Inside Claude Code:

/setup

It can read a documents folder, import a pasted CV, or interview you.

4. Use it

  • /apply <job url> or paste the job text: it scores the fit, drafts a CV and cover letter, and a second agent reviews them.
  • /rank scores a batch of jobs.
  • /interview preps interviews. /outcome tracks results and drafts follow-ups.

Honest note

  • The built-in job-site search (/scrape) is set up for Denmark. In other countries, paste the job post into /apply, or add a portal with /add-portal.
  • Its own page says the defenses are instruction-level, not a sandbox. Read what it writes before you send anything.
  • The LinkedIn skill is for personal use only, since automated access is against LinkedIn's terms.

  • Stars show attention, not quality.

  • Source: github.com/MadsLorentzen/ai-job-search
