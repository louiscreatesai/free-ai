BROWSER: let Claude test your app in a real browser, free

What it is

Claude says "all tests pass" without ever opening your app. Playwright MCP fixes that. It is a free tool from Microsoft that lets Claude open a real browser, click through your app, fill in forms, read the page and tell you what actually happened.

It is Apache 2.0 licensed and has about 38,000 stars on GitHub.

1. Add it to Claude Code (one command)

You need Node.js (version 18 or newer). Then paste this into a terminal:

claude mcp add playwright npx @playwright/mcp@latest

That is the whole install. No account, no key.

2. Ask Claude to use it

Start your app, then tell Claude something like this:

Open http://localhost:3000 in the browser, sign up with a test account, click through the main flow and tell me what breaks. Do not say it works unless you saw it work on the page.

Replace the address with wherever your app runs.

3. What it can do

  • Open pages, click, type, fill forms, pick options, press keys and upload files.
  • Read the page, take screenshots, read the browser console and look at network requests.
  • Run with a visible window by default, so you can watch it work. Add --headless if you want it hidden.

4. Make "tests pass" mean something

  1. Ask Claude to write the test first, run it, and show you it failing.
  2. Then ask it to fix the code and run the test again in the real browser.
  3. If Claude says "done", ask it for a screenshot of the page.

Honest note

Playwright MCP lets Claude look at your app, it does not make Claude right. Watch the first run yourself, and keep your own tests too. It runs a browser on your computer, so only point it at apps and test accounts you are happy for it to click around in.

  • Source and docs: github.com/microsoft/playwright-mcp
