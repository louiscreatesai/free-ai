SLOP: Anthropic's free skill that stops Claude building the same website

What it is

Ask Claude for a website and you often get the same page. Cream background, terracotta button, three identical cards, an arrow on every link. This is a free skill from Anthropic called frontend-design. It is a text file of instructions that Claude reads before it designs a page.

It tells Claude to do three things: - Work out who the page is for and what it must do, if you did not say. - Write a short design plan (colours, fonts, layout), then check the plan against your brief and change any part that looks like the usual default. - Build the page, then criticise its own work.

It also lists the usual AI tells so Claude can steer away from them. They are in "What to look for" below.

It is open source (Apache 2.0) and it lives in Anthropic's skills repo.

  • Source: github.com/anthropics/skills

1. Get the skill

Pick the way that fits how you use Claude.

A. Claude Code, with the plugin (the way the repo's README shows). Paste these into Claude Code, one at a time:

/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills

Claude Code opens a screen for the install. Pick where to install it (for you, or for one project). Heads up: example-skills is a bundle. It installs a dozen of Anthropic's example skills, and frontend-design is one of them.

You can also do it from a normal terminal, without opening Claude Code:

claude plugin marketplace add anthropics/skills
claude plugin install example-skills@anthropic-agent-skills

B. Claude Code, only this one skill. Copy the folder by hand. In a terminal:

git clone --depth 1 https://github.com/anthropics/skills.git
mkdir -p ~/.claude/skills
cp -r skills/skills/frontend-design ~/.claude/skills/

That puts it in ~/.claude/skills/frontend-design/, which Claude Code reads in all your projects. To use it in one project only, copy the folder into .claude/skills/ inside that project instead.

C. Claude.ai in the browser or app. Anthropic's help page says Skills work on Free, Pro, Max, Team and Enterprise plans, and need code execution turned on. On Free, Pro and Max that switch is in Settings, then Capabilities, then "Code execution and file creation". Then open Customize, then Skills, and look for frontend-design in the list. If it is there, switch it on.

If it is not there, upload it yourself. Build a zip with the skill folder inside it (for example, run the B commands above, then cd skills/skills and zip -r frontend-design.zip frontend-design). In Customize, then Skills, click the + button, then "+ Create skill", then "Upload a skill", and pick the zip.

2. Ask for a specific style

The skill follows your words first. Its own text says the brief always wins, even when you ask for one of the usual looks. So if you type "make it modern" or "make it nice", you hand the choice back to the safe default.

Give Claude three things instead: 1. A specific style, in a few words (not "modern"). 2. Who the page is for. 3. What the page must do.

Also say the skill's name in your prompt. It makes sure Claude loads it.

Three prompts you can paste:

Use the frontend-design skill. Build a landing page for a dog walking business in the style of a 1970s hand-painted park sign. The visitors are busy dog owners. The page must make booking a walk the first thing they see.

Use the frontend-design skill. Build a one-page site for a small bakery in the style of a printed newspaper ad, black type on warm paper. The visitors are locals. The page must show the opening hours and the menu without scrolling.

Use the frontend-design skill. Build a pricing page for a budgeting app in a plain Swiss poster style. The visitors are students comparing plans. The page must make the difference between the plans clear at a glance.

3. What to look for

These are the tells of a page Claude made on autopilot. The skill is built to steer away from them. Check your result for them.

  1. The same cream background. A warm cream page with a fancy serif headline.
  2. The same terracotta button. An orange-brown accent. The skill even notes that this colour is Anthropic's own Claude colour, so on your page it reads as a tell.
  3. Identical cards. The content chopped into the same rounded boxes, same corners, same soft shadow, often with a gradient behind them.
  4. An arrow on every link. A small arrow stuck on the end of links and buttons.

The skill lists a few more. A tiny all-caps label above every heading is one. Numbers like 01, 02, 03 on things that are not really steps is another. A near-black page with one bright green accent is a third.

If you see these, say so to Claude, name a different style, and ask it to rebuild.

Honest note

  • It is a demo. Anthropic's repo says its skills are "for demonstration and educational purposes only" and tells you to test them yourself before relying on them.
  • It does not guarantee a unique design. It only gives Claude a plan to avoid the usual defaults. Results vary from run to run.
  • A quick test, one try each, same prompt "build a landing page for a dog walking business". Without the skill, I got a cream page with an orange-red button and a row of three cards. With the skill installed but not named in the prompt, it looked about the same, and I could not tell whether Claude had loaded it. With the skill named in the prompt, the page came out clearly different: cool blue-grey and dark, one yellow-green accent, no arrows. It still had a row of three walker profiles lower down. One try each proves nothing, so test it on your own page.
  • It is the instructions that changed, not magic. If you ask for a look the skill warns about, it will build it.
  • Check the result before you use it. The pages Claude built in my test had made-up names, prices and reviews as placeholders. Replace all of them with your real ones.
