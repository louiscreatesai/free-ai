COURT: put your idea on trial with 12 Claude agents

What it is

Ask Claude about your idea and it usually says it's great. This free skill does the opposite. It puts your idea on trial. A prosecutor argues it will fail, a defender argues it will work, and 12 jurors vote guilty or not guilty without seeing each other's votes. Then a judge makes the final call.

  • The prosecutor: your three strongest reasons it fails.
  • The defender: your three strongest reasons it works.
  • 12 jurors: each plays a different person, like an accountant, a customer, a competitor or a skeptical investor. Each gives one vote and one reason.
  • The judge: counts the votes, names the top reason on each side and gives a ruling: guilty, not guilty, or retrial, plus one thing to do this week.

You get an honest answer, not a yes.

1. Download the skill

  • Download court-trial.zip (for the Claude app)
  • Open SKILL.md (the same skill as a text file)

It's free. I made it, and you can change anything in it.

2. Install it in the Claude app (web or desktop)

  1. Turn on code execution: Settings > Capabilities. Skills need it.
  2. Go to Customize > Skills.
  3. Click +, then Create skill, then Upload a skill, and pick court-trial.zip.
  4. Make sure the skill is switched on in your skills list.

Or install it in Claude Code

Paste this into a terminal (Mac, Linux, or Git Bash on Windows):

mkdir -p ~/.claude/skills/court-trial && curl -o ~/.claude/skills/court-trial/SKILL.md https://louiscreatesai.github.io/free-ai/court/SKILL.md

Then start a new Claude Code session. In Claude Code the 12 jurors run as separate agents, so they really can't see each other's votes.

3. Put your idea on trial

Start a new chat and say something like:

Court: I want to build an app that turns your fridge photos into a week of recipes. $5 a month.

If you leave things out, Claude asks. Answer plainly, then read the verdict.

4. Fix it and ask for a retrial

When the judge has ruled, fix the weakest point and say "retrial". The jury hears the new version and the votes can change.

No skills? Paste it instead

Open SKILL.md, copy everything, paste it into any AI chat (Claude, ChatGPT, Gemini) and add your idea at the end. It works the same, you just paste it each time.

Honest note

In the Claude app one model plays all 14 roles, so the jurors are less independent than in Claude Code, where each is its own agent. Either way it is practice for your thinking, not legal, financial or business advice. A real market can still prove the jury wrong.
