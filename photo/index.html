PHOTO: PhotoCraft, the free open source photo editor

What it is

PhotoCraft is a free, open source image editor written from scratch in Rust. Its README calls it a clean-room reimplementation of Adobe Photoshop. It is dual-licensed MIT or Apache-2.0, has about 70,000 GitHub stars, and runs on Mac, Windows and Linux. It is made by the ArtCraft team and community and is not affiliated with Adobe.

News outlets (Tom's Hardware, Creative Bloq) report that one developer built the Craft apps with Claude. The repo itself does not say that.

Be honest about where it is

  • The README says it is in early alpha and not yet a Photoshop replacement for daily professional work.
  • Listed gaps: AI and generative features, 15 missing tools, typography depth, professional workflows and plug-in compatibility.
  • Some people question the legal side of a clean-room copy of Photoshop, and others call the code AI slop. The developers say no Adobe code was used. Read about it and decide for yourself.
  • Work on copies of your files. A PSD you save again is not byte-identical to the original.

Get it the safe way

  1. Open the official page: github.com/storytold/photocraft
  2. Go to Releases and pick the file for your computer: - Mac: the .dmg marked macos-universal (one file for Apple silicon and Intel) - Windows: the .msi for your chip (x64, arm64 or x86), or the portable .zip - Linux: AppImage, Flatpak, .deb, .rpm or .tar.gz
  3. The README also names getartcraft.com as the easiest way to install it.
  4. Download only from those places. Sites that "host" free Photoshop copies are a classic way to get malware, and anything outside the repo's own Releases page is not from the team.

Try it in five minutes

Open a photo you can afford to lose. Try crop, layers and a filter. Then check one thing you really need, like a file format or a tool, against the README's list of what is missing.

Run it from source (optional)

git clone https://github.com/storytold/photocraft
cd photocraft
cargo run --release -p photocraft -- image.psd

Honest note

  • Stars show attention, not quality.

  • Free and open source does not mean finished. Early alpha means crashes and missing tools are normal.

  • Source: github.com/storytold/photocraft
