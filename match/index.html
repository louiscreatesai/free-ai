Resume Matcher: tailor your CV to every job, free

Resume Matcher is a free, open source tool with over 28,000 stars on GitHub. You paste in a job description and it gives your CV a match score, highlights the keywords, rewrites your CV for that job and writes a matching cover letter. Both export as PDFs.

It runs on your own computer. The first setup takes about 10 minutes, and after that you just open it.

What you need

  • Docker Desktop (free): docker.com/products/docker-desktop. It runs the app for you, so you don't have to install anything else by hand.
  • An AI to do the writing. Pick one:
  • Free: Ollama, which runs an AI model on your own computer: ollama.com
  • Paid per use: an API key from ChatGPT (OpenAI), Claude (Anthropic) or Gemini (Google)

Install it

  1. Install Docker Desktop and open it. Leave it running.
  2. Open Terminal (Mac) or PowerShell (Windows), paste this line and press Enter:
docker run -d --name resume-matcher -p 3000:3000 -v resume-data:/app/backend/data ghcr.io/srbhr/resume-matcher:latest
  1. Wait for the download to finish, then open localhost:3000 in your browser. You should see the Resume Matcher dashboard.

Next time, open Docker Desktop and press play on resume-matcher, or run docker start resume-matcher.

Connect the AI

Free: Ollama

  1. Install Ollama from ollama.com and open it.
  2. In Terminal or PowerShell, download a model. This is the one the setup guide suggests:
ollama pull gemma3:4b
  1. In Resume Matcher, open Settings (localhost:3000/settings) and pick Ollama.
  2. Because the app runs inside Docker, set the Ollama URL to http://host.docker.internal:11434 instead of localhost.
  3. Click Save Configuration, then Test Connection.

Paid: ChatGPT, Claude or Gemini

  1. Get an API key: OpenAI, Anthropic (Claude) or Google AI Studio (Gemini).
  2. In Settings, pick that provider and paste your key.
  3. Click Save Configuration, then Test Connection.

These providers charge for what you use, so keep an eye on your usage page.

Tailor your CV to a job

  1. On the dashboard, upload your main CV (PDF or DOCX).
  2. Paste the job description you're applying to.
  3. Check the match score and the highlighted keywords to see what the job wants that your CV is missing.
  4. Review the tailored CV and the cover letter it writes.
  5. Pick a template and export both as PDFs.

Do this for every application. It takes a minute once it's set up.

Good to know

  • Your CVs are saved on your computer. If you use ChatGPT, Claude or Gemini, the text you tailor is sent to that provider. With Ollama it never leaves your machine.
  • Always read the tailored CV before you send it. Only keep what's true about you.
  • Stuck? Open SETUP.md and paste the error into ChatGPT or Claude. The setup guide also covers the developer install without Docker.
