SKILLS: 5 free Claude skills, and number five builds a whole video

All five install inside Claude Code. A skill is a folder with a SKILL.md that tells Claude how to do a job. Skills can run code, so read each SKILL.md before you install it and only install ones you trust.

1. Anthropic's document skills (Word, PowerPoint, Excel, PDF)

/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills

Then ask: "Use the PDF skill to extract the form fields from this file." These four skills are source-available, not open source.

2. Superpowers

Makes Claude ask what you want, write a plan, and work tests first before it builds. It has over 300,000 GitHub stars and is MIT licensed.

/plugin install superpowers@claude-plugins-official

3. Diagram Design

Turns a sentence into a clean diagram (over 40 types) as one HTML file. MIT licensed.

npx skills add cathrynlavery/diagram-design

4. Scientific Agent Skills

177 science skills that can look things up in over 100 scientific databases. MIT licensed. Installing the skills does not install their Python packages: each skill lists what it needs.

npx skills add K-Dense-AI/scientific-agent-skills

5. HyperFrames (from HeyGen)

You describe a video, Claude writes it as HTML and renders an MP4. Apache 2.0. Needs Node.js 22+ and FFmpeg.

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

Then run /hyperframes:hyperframes and describe the video you want.

Honest note

  • All five are free to install. Claude Code itself needs a paid Claude plan or API credits.

  • Star counts are attention, not proof of quality.

  • Sources: anthropics/skills, obra/superpowers, cathrynlavery/diagram-design, K-Dense-AI/scientific-agent-skills, heygen-com/hyperframes
