VOICE

VOICE: the free ElevenLabs alternative that clones your voice on your own computer

What it is

VoiceStudio is a free, open source (AGPL-3.0) desktop app with about 78,000 GitHub stars. It does voice cloning, voice design, video dubbing, dictation, transcription and audiobooks. The project calls itself a fully local ElevenLabs alternative and says it supports 646 languages (that is the project's own claim).

1. Download it

Easiest: the latest release for Mac, Windows or Linux:

github.com/debpalash/VoiceStudio/releases/latest

Or use the install script the project gives:

macOS and Linux:

curl -fsSL https://voicestudio.sh/install | sh

Windows (PowerShell):

irm https://voicestudio.sh/install | iex

A script piped into your shell runs on your machine, so read it first or use the release download.

2. What your computer needs

  • Apple Silicon Macs use Metal. NVIDIA GPUs on Windows or Linux use CUDA.
  • No dedicated GPU works too, but slower, and setup needs about 5 GB of free disk.
  • Intel Macs only get the interface and need a remote backend.

3. The three things from the video

  1. Clone a voice: add a clean reference recording, then type what it should say.
  2. Turn speech into text.
  3. Dub a whole video into another language.

It also makes audiobooks. The README does not say that dubbing keeps your own voice, so check it on your own file.

Honest note

  • Clone voices only with permission. The project says so too.
  • Model weights and generated-output terms are licensed separately from the app. Check them before you use anything commercially.

  • "Fully local" and the language count are the project's own claims.

  • Source: github.com/debpalash/VoiceStudio
