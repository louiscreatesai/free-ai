MEMORY: give Claude a real memory with claude-mem, free

What it is

When a Claude Code chat fills up, Claude has to compact it, and six hours of work turns into one paragraph. claude-mem is a free, open source plugin that saves what Claude did in each session, condenses it, and feeds the useful parts back into your next chats. You do not have to do anything after you install it.

It is Apache-2.0 licensed and has about 100,000 stars on GitHub.

1. Install it

You need Node.js 20 or newer and Claude Code. In a terminal, run:

npx claude-mem install

Or, inside Claude Code, run these two commands:

/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem

Then restart Claude Code. Context from your previous sessions shows up in new sessions automatically.

Do not run npm install -g claude-mem. That installs only the library, not the plugin.

2. The sign-in (you can skip it)

The installer can ask you to sign in with an email link. Signing in starts a 30 day free trial of claude-mem's own memory service. When the trial ends, memory falls back to your Claude plan unless you subscribe, so it uses part of your plan. You can skip the sign-in and choose your own provider instead. The README explains how to skip it with the --provider flag or CLAUDE_MEM_ONLINE_OPTIN=false.

3. Use it

  1. Work as usual. It captures what Claude does and makes short summaries on its own.
  2. Start a new session the next day. The useful parts from before are already there.
  3. To look something up, ask Claude to search your past work, for example "what did we decide about the button?". claude-mem has a search skill for this.
  4. Put <private> tags around anything you do not want saved.

Honest note

claude-mem is made by a third party, not by Anthropic. It records what Claude does in your sessions, so keep secrets out of your chats and use the <private> tags. Memory is helpful, not magic: it saves summaries, so Claude can still miss details.
