CODES: 100 ChatGPT shortcuts (5 tested, 95 to try)

What it is

A code is a few letters you type at the start or the end of your message so ChatGPT knows how to answer. Like /human Explain taxes or Explain taxes EL10.

They are prompt tricks, not official commands. ChatGPT reads them as instructions, so results can change with the model and the question. Nothing to install.

The 5 from the video, tested

I ran each one in my own ChatGPT on 10 October 2026, with the same question: "Explain taxes". I ran each once, so your results may differ.

  1. /human: a small change. Same layout as the plain answer, plus one friendlier line: "Think of a country as a giant shared household."
  2. EL10: a clear change. It starts like this: "Imagine you live in a town with 1,000 people." It uses a EUR 100 summer job as the example.
  3. X10 think: longer and deeper, not smarter. The answer was about 2.4 times longer (4,781 characters against 2,004) and added economics. It did not look like extra thinking.
  4. killcritic: blunter, not more honest. For the idea "sell ice cream to penguins in Antarctica", the plain answer was already critical: "Great pitch. Terrible business model." and 2/10. With killcritic it said "Business idea: 0/10. Comedy potential: 10/10."
  5. alt 3: a clear change. You get three explanations in one answer: the simple one, a pizza analogy and the economics one.

How to use them

  • Put the code at the start or the end of your message: /human Write me a birthday message or Write me a birthday message EL10.
  • You can stack two: EL10 alt 3 Explain inflation.
  • If a code does nothing, say what you want in plain words. The code is only a shortcut for that sentence.

The full list of 100

The first 5 are tested (above). The other 95 are shortcuts for everyday instructions that ChatGPT already understands. I have not tested all of them, so treat them as starting points and keep the ones that work for you.

Tone and voice

  • ELI5: explain it like I'm five
  • TLDR: give a two-sentence summary first
  • BLUF: bottom line first, then the details
  • /formal: formal business tone
  • /casual: relaxed, everyday tone
  • /funny: add a bit of light humor
  • /short: keep it under 100 words
  • /long: go deep, with sections
  • /friend: talk like a friend giving advice
  • /coach: encouraging and direct, like a coach

Explain

  • ELI15: explain it like I'm fifteen
  • analogy: explain it with an everyday comparison
  • example: add one real-life example
  • steps: number the steps
  • why: explain why, not just what
  • mistakes: list the common beginner mistakes
  • no jargon: define every term you use
  • compare: compare the options in a table
  • pros cons: list pros and cons
  • faq: turn it into five questions and answers

Think

  • step by step: show your reasoning step by step
  • assumptions: list your assumptions first
  • double check: check your answer once before you reply
  • what if: add three "what if" cases
  • steelman: give the best version of the other side
  • devil: play devil's advocate
  • premortem: imagine it failed and list why
  • rank: rank the points by importance
  • tradeoffs: name the trade-offs
  • ask first: ask me up to three questions before you answer

Feedback

  • brutal: honest feedback, no sugar
  • fix it: rewrite it better and show what changed
  • score: score it out of 10 and say why
  • weakest: point to the weakest part only
  • strongest: what is working, so I keep it
  • top 3 fixes: give me the three best fixes
  • red team: find the holes in my plan
  • blind spots: what am I missing
  • second opinion: answer as a different expert would
  • critique yourself: critique your own answer after

Formats

  • table: put it in a table
  • bullets: short bullet points
  • checklist: a checklist I can tick off
  • timeline: a timeline with dates or steps
  • cheat sheet: one page I can screenshot
  • template: a fill-in template
  • script: a spoken script, with timings
  • outline: an outline with headings
  • json: output as JSON
  • csv: output as CSV
  • email: format it as an email
  • tweet: fit it in one post
  • caption: write it as a social caption
  • 10 headlines: ten headline options
  • one line: say it in one sentence

Writing

  • shorter: cut it by half
  • clearer: rewrite it so anyone gets it
  • simplify: use plain, short words
  • expand: add detail and examples
  • hook: give me five opening lines
  • proofread: fix mistakes only, change nothing else
  • titles: ten title ideas
  • story: turn it into a short story
  • openers: five ways to start this message
  • cta: add a clear call to action

Study

  • quiz me: ask me questions one at a time
  • flashcards: make question and answer cards
  • key terms: list the terms I must know
  • teach back: I explain it, you correct me
  • my mistakes: tell me what I got wrong and why
  • practice: give me five practice problems
  • mnemonic: a trick to remember it
  • study plan: a plan for the days I have
  • exam questions: likely exam questions with answers
  • summarize: summarize this chapter or text

Work

  • action items: list who does what by when
  • agenda: build an agenda for this meeting
  • status update: a short update for my boss
  • reply: draft a reply to this email
  • negotiate: give me a script to ask for more
  • 30 sec pitch: a 30 second pitch
  • job post: write the job post
  • resume bullets: strong bullets for my resume
  • interview: practice interview questions

Code

  • find bug: find the bug and fix it
  • comment: add comments to this code
  • tests: write tests for this code
