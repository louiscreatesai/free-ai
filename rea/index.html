REA

REA: the free tool that lets Claude take apart any app or website

What it is

REA is a free, open source (MIT) tool that gives an AI agent such as Claude Code the tools to inspect software, trace how it works and report back with the evidence behind each answer. It was the number one trending repo on GitHub in the week to 20 October 2026, with 201,065 new stars (341,285 in total). Stars show attention, not quality, so read what it does before you trust it.

The analysis runs on your own computer. Your agent's model provider still has its own data policy for what the agent sees.

Before you start

  • Node.js 22.x (22.19 or newer), 24.x (24.11 or newer) or 26+, plus npm.
  • An AI agent that supports local MCP servers: Claude Code, Codex, Cursor, Gemini CLI and more. Claude Code needs a paid Claude plan or API credits.

1. Set it up

Run this in your terminal:

npx rea-agents setup

Choose your agents, review the changes it proposes and approve them. It keeps backups of your existing config. Then restart your agent.

2. Optional: install the command line tool

npm install --global rea-agents
rea --help

Update later with rea update.

3. Ask your agent

Try something like: "Use REA to investigate how the export button works on this website and show me the evidence." Then: "Build a similar feature into my project."

What it can look at

Websites and browser captures, JavaScript and Electron apps, Android apps, .NET apps, native binaries (these need Hopper, Ghidra or IDA), firmware, SQLite databases and more. What you need depends on the target, so check the README for yours.

Honest note

  • REA is for lawful research, education, interoperability and software preservation, and for software you own or are authorized to examine. Only use it on software you own or have permission to study.
  • Commercial tools such as IDA Pro and Hopper need their own legal licenses.
  • Runtime capture runs the target with your user permissions, so read the runtime guide first.
