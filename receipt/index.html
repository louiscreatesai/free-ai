RECEIPT: see where your Claude limit went, free

What it is

You hit your Claude limit and nobody shows you a receipt. ccusage is a free, open source tool that reads the usage files already on your own computer and prints a report: tokens and cost by day, week, month, session and model. It also shows Claude Code's 5 hour windows, so you can see which one burned your limit.

It is MIT licensed and has about 19,000 stars on GitHub.

1. Run it (one command)

You need Node.js installed. Then paste this into a terminal:

npx ccusage@latest

That prints your usage by day. Nothing to install, nothing to sign up for.

2. The other reports

npx ccusage@latest daily
npx ccusage@latest weekly
npx ccusage@latest monthly
npx ccusage@latest session
npx ccusage@latest blocks
  • session shows which conversations used the most.
  • blocks shows Claude Code's 5 hour windows.
  • Add --since 2026-10-01 to start from a date, or --json if you want the numbers as data.

It also reads usage from other coding agents it detects, such as Codex and Gemini CLI.

3. How to read your receipt

  1. Look at the day with the biggest bar. That is your Monday.
  2. Open session and find the one conversation that ate the most. That is usually one long chat that read the whole project again and again.
  3. Start a fresh chat for each new task, so a long chat does not carry its whole history every time.

Honest note

ccusage shows how many tokens you used and what they cost. It does not show what each message said, or why one chat used so much: that part is up to you to work out from the sessions. The cost column is an estimate. It reads local usage data on your computer and is made by a third party, not by Anthropic.

  • Source and docs: github.com/ccusage/ccusage
