CITE: free skills that check every source in your paper is real

What it is

AI can write a source that looks perfect and does not exist. Academic Research Skills is a free set of Claude Code skills, made by Imbad0202 and shared on GitHub. It includes a citation check for a finished paper: it looks for each source and checks whether it says what your sentence claims.

It is licensed CC BY-NC 4.0. That means free for non-commercial use, like school work or a personal project, and not for paid work.

  • Source and docs: github.com/Imbad0202/academic-research-skills

1. What you need

  • Claude Code installed.
  • An Anthropic API key. The README lists ANTHROPIC_API_KEY as a requirement, set in your terminal or the first time you run claude. Using an API key is billed by use, so check your own setup before you start.

2. Install it

Paste these two lines into Claude Code, one at a time:

/plugin marketplace add Imbad0202/academic-research-skills
/plugin install academic-research-skills

3. Check your paper

Open Claude Code in the folder where your paper is saved. Type:

Check citations

then paste your paper or attach the file. The project's changelog also names a slash command, /ars-citation-check, which should do the same.

The README does not describe exactly what the report looks like, so read what it prints and write down every source it flags.

4. The deeper check (optional)

The project has an opt-in claim audit. Turn it on with ARS_CLAIM_AUDIT=1. It fetches each source and judges whether the source really supports the sentence you attached it to. The README says this judge has not yet been calibrated against a live test, so treat it as a second look, not a verdict.

5. What to do with the result

  1. Open every flagged source yourself.
  2. If you cannot find it, or it does not say what you wrote, remove it or replace it with one you have read.
  3. Do the same for the sources you rely on most, even the ones it passed.

Honest note

  • It misses some. The README says some checks are sampled or run by a language model, so a made-up source that is described consistently can pass.
  • The project's own showcase paper is a warning: a later audit still found problems in 21 of its 68 references after three rounds of checks (the README says the current checks have not been measured on that paper).
  • It checks that sources exist and match your claim. It does not prove the research behind them is real.
  • Cost: the README estimates about US$3 to $7 for a full pipeline run on a 15,000 word paper. That figure is for the whole pipeline, not for the citation check alone, and I could not find a figure for the check alone.
  • You are still responsible for every source you hand in. This is a checker, not a guarantee, and it is for checking your own work, not for writing it for you.
