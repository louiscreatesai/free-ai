Find Skills: the Claude skill that installs the other skills

What it is

Find Skills is the most installed skill on skills.sh, with 3.7 million installs. It doesn't do your task itself. When you ask Claude for something it can't do well yet, Find Skills finds the best skill for that job and installs it for you.

It's free and MIT licensed. Get it here: skills.sh/vercel-labs/skills/find-skills

1. The one-line install

You need Node.js on your computer (it comes with npx). Get it from nodejs.org if you don't have it.

Open a terminal in your project, paste this and press Enter:

npx skills add vercel-labs/skills --skill find-skills

Want it in every project on your computer, not just this one? Add -g:

npx skills add vercel-labs/skills --skill find-skills -g

2. Just ask

You don't need a special command. Ask Claude the way you'd ask a person:

  • "Find a skill for SEO audits"
  • "How do I add tests to this app?"
  • "Is there a skill that can make slide decks?"

Find Skills checks the skills.sh leaderboard first, then searches by keyword, and installs the one it picks so Claude can use it right away.

3. How it picks (so you don't get junk)

It checks three things before it recommends a skill:

  1. Installs. It prefers skills with 1,000+ installs and is careful with anything under 100.
  2. Who made it. It trusts official sources like Anthropic, Vercel and Microsoft.
  3. GitHub stars. Repos with under 100 stars get a second look.

4. It works beyond Claude

The same skills install into Claude Code, Codex, Cursor, OpenCode and 75 more AI coding tools.

5. Two handy extras

  • See what you have: npx skills list
  • Update every skill you've installed in one go: npx skills update

Honest note

A skill can run code on your machine. Read what a skill does before you let it run, and stick to well-known sources.
