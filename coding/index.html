4 free Claude Code plugins, with the install commands

All four are free and open source. Install them in this order and you're done in about 10 minutes.

Commands that start with / go in the Claude Code prompt. The others go in Terminal (Mac) or PowerShell (Windows).

1. Ponytail: less code, lower cost

It makes Claude code like the laziest senior dev in the room: it writes the smallest thing that works. Its own test on real Claude Code sessions found about 54% less code and about 20% lower cost.

You need Node.js installed. Send these as two separate prompts:

/plugin marketplace add DietrichGebert/ponytail

/plugin install ponytail@ponytail

Repo: github.com/DietrichGebert/ponytail

2. OmniRoute: never stop at your usage limit

One local endpoint that sits between Claude Code and 350+ AI providers. When one runs out, it moves to the next one on its own. By its own count the free plans add up to about 1.6 billion free tokens a month.

npm install -g omniroute
omniroute
  1. Open the dashboard at localhost:20128.
  2. Go to Providers and connect the ones you want. OpenCode Free works with no signup.
  3. Start Claude Code through it. auto lets OmniRoute pick the model and fall back for you:
omniroute run claude --model auto

The catch: some free providers have terms that forbid this kind of use. OmniRoute marks those in its catalog, so read them before you connect one.

Repo: github.com/diegosouzapw/OmniRoute

3. Graphify: Claude stops rereading your files

It turns your whole project into a knowledge graph that Claude can search, instead of opening the same files again and again. Mapping the code is free and stays on your machine.

You need uv (or pipx):

uv tool install graphifyy
graphify install

Then, inside your project in Claude Code:

/graphify .

It writes a graphify-out folder with the graph, a clickable map (graph.html) and a short report.

Repo: github.com/Graphify-Labs/graphify

4. Agent Skills by Addy Osmani: work like a senior engineer

25 skills that walk Claude through the whole job: /spec, /plan, /build, /test, /review and /ship. The right skill switches on by itself for what you're doing.

Send these as two separate prompts:

/plugin marketplace add addyosmani/agent-skills

/plugin install agent-skills@addy-agent-skills

Or, for any coding agent:

npx skills add addyosmani/agent-skills

Repo: github.com/addyosmani/agent-skills

Check it worked

Restart Claude Code, then type /plugin to see Ponytail and Agent Skills listed. Type /graphify to check Graphify is there.
