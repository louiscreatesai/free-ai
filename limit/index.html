LIMIT: the free caveman plugin that saves your Claude usage limit

What it is

Caveman is a free plugin (Apache 2.0, over 100,000 GitHub stars) for Claude Code and other coding agents. It makes Claude answer in fewer words and shrinks the files and tool output Claude reads. Code, commands, paths and error messages stay exactly the same.

Its own test on 54 Claude Code runs: sessions used 33.2 percent fewer input tokens (885,793 down to 591,673). That is the project's own number, and results change with your work.

1. Install Caveman

Simplest:

npx @caveman-ai/cli@latest

Or as a Claude Code plugin:

claude plugin marketplace add JuliusBrussee/caveman
claude plugin install caveman@caveman

It needs Node.js 22.13 or newer.

2. Turn the telemetry off

The Caveman command line tool sends usage telemetry by default. Switch it off with:

caveman telemetry off

or set DO_NOT_TRACK=1.

3. Add Context Mode (optional)

Keeps giant tool output out of your chat. Its own example shrinks 315 KB to 5.4 KB. It uses the Elastic License 2.0, which is source-available, not open source.

/plugin marketplace add mksglu/context-mode
/plugin install context-mode@context-mode

Restart Claude Code or run /reload-plugins, then check with /context-mode:ctx-doctor.

4. Built in, no install

  • /context shows what is filling your chat.
  • /compact frees space without starting over.
  • /clear starts a fresh, empty chat.
  • /usage shows your plan usage limits.

Honest note

  • Caveman's own page says that simply asking Claude to "answer concisely" already gets most of the saving on answers. The bigger win is the reading side.
  • Savings only matter where you are limited by tokens, like your Claude plan limit.

  • Star counts are attention, not proof of quality.
