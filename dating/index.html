DATING: a panel of 7 Claudes that roasts your dating profile

What it is

Nobody tells you why they swiped left. This free skill makes seven Claudes read your dating profile first, tells you what to fix, then rewrites it in your own voice. Type /dating-panel and paste your profile text.

Each of the seven reads it alone and never sees what the others said:

  • The stranger: reads only the first lines. In one sentence, what is this person like? If they cannot say, it answers LOST.
  • The fast swiper: gives it two seconds. SWIPE RIGHT, SWIPE LEFT or MAYBE, and what decided it.
  • The match who wants the same thing: is it clear what you are looking for?
  • The best friend: knows you. Does this sound like you, and which line sounds fake?
  • The skeptic: hunts clichés and empty lines ("love to laugh", "partner in crime") and quotes every one.
  • The first message writer: is about to write to you. Is there anything specific to reply to?
  • The safety reader: is there too much about you in here (workplace, surname, handles, where you are and when)?

Then it merges everything into one list of what to fix, worst first, each with the exact line it is about and how many of the seven flagged it. Then it rewrites your profile: three bios and better answers to your prompts, in your voice.

It never invents anything. If a fix needs a fact it does not have (a hobby, a job, a story), it leaves [ADD: what you need] and asks you at the end. It will also tell you when a line is not true, because a line that is not true costs you on the first date.

1. Download the skill

  • Download dating-panel.zip
  • Open SKILL.md (the same skill as a text file)

It's free. I made it, and you can change anything in it.

2. Install it in Claude Code

Paste this into a terminal (Mac, Linux, or Git Bash on Windows):

mkdir -p ~/.claude/skills/dating-panel && curl -o ~/.claude/skills/dating-panel/SKILL.md https://louiscreatesai.github.io/free-ai/dating/SKILL.md

Then start a new Claude Code session. In Claude Code the seven readers run as separate agents, so they really can't see each other's answers.

Or install it in the Claude app

  1. Turn on code execution: Settings > Capabilities. Skills need it.
  2. Go to Customize > Skills.
  3. Click +, then Create skill, then Upload a skill, and pick dating-panel.zip.
  4. Make sure the skill is switched on in your skills list.

3. Run it on your profile

Start a new chat and type:

/dating-panel

and paste your profile text after it: the bio, your prompt answers, and a line describing each photo. Add one line on what you are looking for. If you leave that out, it asks you first.

Leave out your name, phone number, social handles and workplace when you paste. It never needs them.

4. What you get

Everything is saved in a new folder called .dating-panel/<date>/ next to where you ran it:

  • PANEL.md: the seven verdicts and the numbered fixes, worst first.
  • PROFILE-IMPROVED.md: three new bios, better prompt answers, and the [ADD: ...] questions at the end.

In the chat you see one line per reader, the five worst fixes, the before and after verdict of the stranger test, and where the files are.

Honest note

This is a structured second opinion made by language models. It does not promise matches or dates. It reads only the words you paste, so it cannot judge photos. It will not rate your looks. If your Claude cannot start separate agents, one model plays all seven roles one after another, and they will agree with each other more than seven separate readers would.
