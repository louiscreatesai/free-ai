LEASE: Anthropic's free legal plugin that flags the risky lines in a contract

What it is

Claude will happily tell you a contract "looks great". This is the plugin Anthropic released for contract review. You give it a contract and it reviews it against your playbook (your own list of what you will and will not accept), flags where the contract differs, suggests changes and explains what each risky clause could mean for you.

It is open source (Apache-2.0), and it works in Cowork and in Claude Code.

Read this first: Anthropic built it for in-house legal teams reviewing company contracts, not for a home lease. So I wrote a starter playbook for renters. It is mine, not Anthropic's, and it is below.

  • Source and docs: github.com/anthropics/knowledge-work-plugins

1. Install it

Paste these into a terminal:

claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install legal@knowledge-work-plugins

2. Add the renter playbook

The plugin reads a playbook file called legal.local.md, saved in a folder called .claude inside your project folder.

  • Download legal.local.md

Put it at .claude/legal.local.md in the folder where you will run Claude Code. The plugin's default playbook reflects United States positions (Delaware, New York and California), so if you rent somewhere else, this file matters.

3. Run it on your lease

In that folder, start Claude Code and type:

/review-contract path/to/my-lease.pdf

You can also paste the lease text, or a link, after the command.

4. What you get

A review of the contract against the playbook: the clauses that look fine, the ones to ask about and the ones that look like red flags, each with the line it is about. Use it to build a list of questions for the landlord before you sign.

Honest note

  • It is not legal advice. Anthropic says so in its own README: always check conclusions with a qualified legal professional.
  • It is built for company legal teams and its default positions are American. The renter playbook above is my own template, so try it on a sample lease first and see what it flags.
  • It cannot tell you what is allowed where you live. Ask a local tenant organisation or a lawyer about anything it flags.
  • Never sign because an AI said it looked fine.
