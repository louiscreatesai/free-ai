SWITCH: Move what ChatGPT remembers about you into Claude

If you commented IMPORT, you are in the right place too.

What it is

Anthropic has a page that helps you bring your saved preferences and context from another AI into Claude, so you do not start from zero. You ask ChatGPT to list what it has stored about you, then you paste that list into Claude's memory settings. Claude turns it into memory entries.

It works on the Free plan, and on Pro, Max, Team and Enterprise too. Anthropic's help page says you can use it on the web and in the Claude desktop app.

It is a copy and paste that you do yourself. Nothing connects the two apps.

  • Anthropic's import page: claude.com/import-memory
  • Anthropic's help article: Import and export your memory from Claude

1. Open Anthropic's import page

Go to claude.com/import-memory. It shows two steps. Step 1 has a "Copy prompt" button. Step 2 sends you to Claude's memory settings.

Before you start, check that memory is switched on in ChatGPT. The prompt asks ChatGPT to list what it has stored about you, so if ChatGPT has nothing saved, there is nothing to list. Look for memory in ChatGPT's settings. I could not check the exact menu names, so use ChatGPT's own search or help if you cannot find it.

2. Copy the prompt into ChatGPT

Press "Copy prompt" on Anthropic's page, or copy it from the help article above. Open a new chat in ChatGPT and paste it.

I am not repeating the prompt here on purpose. Always take it from Anthropic's own page so you get their exact wording.

The prompt asks ChatGPT to list every memory it has about you, in one code block. Anthropic's help page says you can edit the prompt first to leave out anything sensitive. Do that if there is something you do not want Claude to store.

When ChatGPT answers, copy the whole code block.

3. Paste the answer into Claude's memory settings

In Claude, follow the path Anthropic's help page gives:

  1. Go to Settings, then Memory.
  2. Select "Start import".
  3. Paste the text you copied from ChatGPT into the box.
  4. Click "Add to memory".

Claude then picks out the key information and saves it as separate memory entries. You can also reach this screen from the "Start importing to Claude" button on Anthropic's import page.

If your menu shows Memory under Settings, then Capabilities instead, you have the older version of memory. Anthropic's help article has a separate set of steps for it. There you find Memory under Settings, then Capabilities, select "Start import", paste, and click "Add to memory".

4. Check what Claude kept

Do not skip this. Open the memory panel and read the entries Claude saved.

  • Anything wrong, old or private: tell Claude to change or remove it, using the "Tell Claude what to change or remove" box in Settings, then Memory.
  • You can also start a new chat with the "See what Claude learned about you" button. It asks Claude: "I updated my memory. What did you learn about me?"
  • Anthropic says you can see and edit everything Claude remembers.

What it will not do

  • It does not move your old chats. Anthropic's page is only about memory, meaning preferences and context.
  • It may not keep everything. Anthropic says Claude's memory focuses on work topics, so personal details that are not about work may not be kept.
  • Some things are never saved to Claude's memory, even if you ask, such as government ID numbers and financial account numbers.
  • It is not guaranteed. Anthropic says memory imports may not always work.

Honest note

  • Anthropic calls memory import experimental and still being developed. Claude may not always take in what you paste.
  • It is a copy and paste. Read what Claude kept before you trust it.
  • Do not paste anything private that you would not want stored. Remove it from the text first, or take the entry out afterwards.
  • What you get depends on what ChatGPT has saved and on what Claude decides to keep, so do not expect a perfect copy.
