MCP

MCP: the 4 plugins that give Claude real powers, with the install commands

What it is

An MCP is a plugin that connects Claude to something outside the chat. Without one, Claude can only talk. With these four it can search the web, read any website, drive a real browser and read the latest docs.

Paste each command into a terminal (Node.js 18 or newer is needed for all four). They are for Claude Code.

1. Perplexity: web search and deep research

You need a Perplexity API key from console.perplexity.ai. The API is billed by use, so check the price on that page before you add a card.

claude mcp add perplexity --env PERPLEXITY_API_KEY="your_key_here" -- npx -y @perplexity-ai/mcp-server

It gives Claude four tools: search, ask, research (the deep one, which can take minutes) and reason.

2. Firecrawl: scrape any site, click through it, pull its brand

Make a Firecrawl account and copy your API key (it starts with fc-).

claude mcp add firecrawl -e FIRECRAWL_API_KEY=fc-YOUR_API_KEY -- npx -y firecrawl-mcp

Firecrawl can also return a site's branding (logo, colors, fonts) when you scrape it. Ask Claude: "Scrape this site and give me its brand colors and fonts."

3. Playwright: drive a real browser (free, by Microsoft)

No account and no key.

claude mcp add playwright npx @playwright/mcp@latest

Claude can open pages, click, fill forms, read the page and test your app. It is Apache 2.0 licensed and has about 38,000 stars on GitHub.

4. Context7: the latest docs, so Claude stops guessing

Get a free key at context7.com/dashboard (it raises your rate limits).

claude mcp add --scope user context7 -- npx -y @upstash/context7-mcp --api-key YOUR_API_KEY

Then end a prompt with "use context7" and Claude reads the current docs for the library you named. It is MIT licensed.

Check they work

Start claude and type /mcp. All four should show as connected.

Honest notes

  • Perplexity and Firecrawl need API keys, and both are paid beyond their free allowances. Playwright is free. Context7 has a free key.
  • Never paste a key into a chat or a public repo. The commands above store it on your own computer.

  • Every MCP gives Claude more access. Add the ones you need, not all of them at once.

  • Sources: Perplexity, Firecrawl, Playwright, Context7
